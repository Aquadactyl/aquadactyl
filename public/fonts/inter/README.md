# Inter

Unmodified variable WOFF2 fonts from [the official Inter repository](https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470/docs/font-files), pinned to commit `353b61b9f4430d5f420d56605a6e7993e0941470`.

Both upright and italic fonts support weights 100–900. The panel serves them locally through `../inter.css`, with `font-display: swap`. The original license is included in [LICENSE.txt](LICENSE.txt).
