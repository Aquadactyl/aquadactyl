# Inter

The active stylesheet uses unmodified variable WOFF2 subsets distributed by Google Fonts. Latin, extended Latin, Cyrillic, Greek, and Vietnamese have separate Unicode ranges, so browsers request only the subsets needed for the displayed text. Upright and italic fonts support weights 100–900 and are served locally with `font-display: swap`.

Each source URL, SHA-256 checksum, style, Unicode subset, and file size is recorded in [subsets.json](subsets.json). The corresponding license is [GOOGLE-FONTS-LICENSE.txt](GOOGLE-FONTS-LICENSE.txt). No Google-hosted requests are needed at runtime.

The older full-font files from [the official Inter repository](https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470/docs/font-files), with their original [LICENSE.txt](LICENSE.txt), remain available for previously cached stylesheets.
